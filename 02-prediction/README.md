# Enhetsregister Prediction

Small predictive analysis of Norwegian company data from **Brønnøysundregistrene**.


## What it does

- Loads a subset of relevant columns from the raw CSV
- Cleans and prepares the data 
- Trains a baseline model, a logistic regression model, and a random forest model on relevant features from the dataset, where the target is "industry"
- Visualises the accuracy of the models, and feature importance for the random forest model

## How to run

- Follow the instructions in the README in the main folder of the repository
- Run the "main.py" file in this folder
